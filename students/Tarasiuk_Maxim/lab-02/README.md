# PortfolioService

`PortfolioService` — это центральный сервис системы «Деньги растут», отвечающий за управление списком активов (портфелем) инвестора и расчет ключевых финансовых показателей, в частности — доходности.

## Структура
Проект использует **гексагональную архитектуру (Ports and Adapters)**.
Доменный слой полностью изолирован от внешних воздействий и не имеет зависимостей от других слоев.
Все вызовы внешних систем (база данных брокерских счетов, сторонние сервисы котировок) производятся через исходящие порты (интерфейсы).

См. `Architecture.md` для получения подробной информации.
